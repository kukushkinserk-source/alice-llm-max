# Alice LLM Max — исправленная версия ituzovlab-alice

Основа: https://github.com/ituzov/ituzovlab-alice (MIT, см. LICENSE).

## Что изменено

- Ответы >1024 символов не теряются: фраза «продолжай» читает следующий фрагмент уже готового ответа, без повторного обращения к LLM.
- Выключены логи вопросов и ответов, не пишем ответы API при ошибках.
- Для вебхука обязательно задаётся секретная длинная случайная строка `ALICE_WEBHOOK_SECRET`: просто знание `skill_id` больше не даёт прямого доступа к платному API.
- Проверка входного JSON, ограничение размера HTTP-запроса и таймаут к API.
- Память по-прежнему хранится только в RAM; после перезапуска теряется.

## Как выложить в Timeweb App Platform

App Platform пока разворачивает проект из Git-репозитория, не из ZIP. Поэтому:

1. Создать собственный GitHub-репозиторий (можно приватный, но тогда придётся подключить свой GitHub к Timeweb; для простоты подойдёт публичный репозиторий БЕЗ ключей).
2. Распаковать этот ZIP, загрузить файлы из корня папки в репозиторий. Файлы `.env` с секретами не загружать! В комплекте только `.env.example` с пустыми полями.
3. В Timeweb → App Platform → Создать → подключить репозиторий; Node.js 22, Express, запуск `node server.js`, проверка `/health`.
4. В переменных окружения Timeweb указать `API_KEY`, `BASE_URL`, `MODEL`, `ALICE_WEBHOOK_SECRET` (и позже `ALICE_SKILL_ID`). Не вставлять секреты в публичные файлы.
5. После запуска проверить `https://<домен-приложения>/health` → `ok`.
6. В Яндекс Диалогах создать приватный навык и указать Webhook URL: `https://<домен-приложения>/hook/<секрет>`.
7. В Яндекс Диалогах протестировать запуск и длинный ответ. После теста скопировать `session.skill_id` из JSON-запроса тестирования и добавить переменную `ALICE_SKILL_ID` в Timeweb, затем перезапустить приложение.

### Секрет URL

На Windows PowerShell (без сторонних программ):

```powershell
$b = New-Object byte[] 24
[System.Security.Cryptography.RandomNumberGenerator]::Create().GetBytes($b)
[BitConverter]::ToString($b).Replace('-','').ToLower()
```

Сохранить полученную строку в переменной `ALICE_WEBHOOK_SECRET` и добавить к адресу вебхука после `/hook/`.

## Голосовой запуск

- «Алиса, запусти навык Умник» — открывает навык, затем можно задавать вопросы подряд.
- «Алиса, спроси у Умника, почему небо синее?» — открывает навык и сразу передает вопрос. Название «Умник» — пример, фактическое активационное имя задаётся в Яндекс Диалогах.
- Навык остаётся активным до выхода или автоматического тайм-аута Яндекса. После этого потребуется активационная фраза вновь.

## Ограничения

- Облачное распознавание речи и синтез ответа Яндексом остаются обязательными.
- Из обычного режима Алисы нужно запускать приватный навык голосовой фразой.
- Каждая часть требует команды «продолжай» (лимит 1024 символа в ответе навыка).
- Сервис хостинга Timeweb оплачивается отдельно от вызовов модели.
- Секрет в URL снижает риск злоупотреблений, но не является криптографической проверкой подлинности Яндекс Диалогов. Не публиковать полный адрес вебхука.
