# Alice LLM Max — приватный навык с AI Gateway

Модификация [ituzovlab-alice](https://github.com/ituzov/ituzovlab-alice) под Яндекс Станцию Макс (YNDX-0008). Оригинальный проект распространяется по лицензии MIT (см. LICENSE).

**Для начала прочти [README-START-RU.md](README-START-RU.md).**

Основные улучшения: чтение длинных ответов частями без повторных обращений к LLM, отсутствие логирования реплик, секретный webhook URL, базовая проверка входящих запросов.

Приложение работает через Яндекс Диалоги и Timeweb AI Gateway, поэтому зависимость от облака Яндекса сохраняется. Код тестировался с имитацией ответа модели; фактическая работа с Timeweb и Яндекс Станцией требует проверки после развёртывания.

- v1.2: исправлена обработка активационного запроса Яндекс Диалогов; `request.command` используется без подмены на `original_utterance`.
